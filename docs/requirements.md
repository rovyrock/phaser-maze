# 找茬需求文档

工作名「找茬」。玩法是竖屏里上下两张图，找出它们的不同。第 1、2 关用外部茬图包，第 3 关由规格生成。不从网页文章抓取别人的插画放进关卡。

玩家能感知的规则以本文为准。模块、数据格式和进度见 `docs/development.md`。改变玩法、界面或发布约束时，先改本文，再改开发文档和代码。

## 产品目标

第一版是竖屏、单手、限时的对比找茬。一关有两张同样大小的图，上面一张、下面一张。两张图大体相同，只有若干处不一样。玩家点中任一处不同即算找到，上下两张图的同一位置都套上圈。倒计时结束前找齐即过关。

发布目标是微信小游戏。浏览器版是开发入口，也是可独立发布的 H5 版本。

参考的是上下排列的双图找不同，不是单张场景里收集异常物件，也不是左右并排。

## 第一版范围

包含：

- 上下两张图，点中不同处后两边同时套圈
- 两张图之间用圆点表示找到了几个
- 首页、结算、本地进度，以及 3 关可玩内容
- 每关 3 次提示，提示在上下两张图上同时标出下一个未找到的位置
- 竖屏 750×1334，全部界面画在画布上
- 进关前单独加载这一关的两张图。加载完成前不开始倒计时
- 第 1、2 关接入外部茬图包；第 3 关用规格生成两张茬图和 `level.json`

不包含，留到后续版本：

- 扣命、错误震动惩罚
- 单张场景里的大图、状态切换、滑动、双击、拖拽
- 登录、好友排行榜、分享裂变、激励视频加时
- 多剧本大厅、钥匙、战利品

点错不扣时间，也不扣命。时间耗尽且未找齐则失败，可以无限次重试。重试重置本关进度、提示次数和倒计时，不改变已解锁关卡。

## 核心规则

一关有一个倒计时，单位是秒，从关卡配置读取。两张图都摆好之后才开始倒数。结算界面和游戏被切到后台时，倒计时暂停。回到前台后继续。

不同处的数量就是本关目标。已经找到的位置再点不重复计数。点在上图或下图的对应位置，效果相同。找齐后立即胜利，不必等倒计时结束。倒计时归零且仍有未找到的位置则失败。胜利或失败后，两张图不再响应。

提示只作用于还没找到的位置，按关卡顺序找第一个。提示在上下两张图上同时画圈，并显示提示文案。提示次数用完后，按钮不可再点。提示不暂停倒计时。

点在图内但没有点中不同处时，给出一次很短的无效反馈，不改变进度和倒计时。点在两张图以外不反馈。

## 界面

设计分辨率 750×1334，竖屏，按比例适配并居中。刘海和底部横条内不放关键按钮。

- 左上角是返回首页。返回不记为本关失败，也不改解锁进度。
- 顶部其余位置放关卡名、已找到数量和剩余时间。
- 中部是上下两张图，宽度相同、左右对齐，中间留一排圆点。圆点个数等于本关不同处，找到的亮起。
- 点中后，两张图上各出现一个圈，圈心落在该不同处。
- 底部放提示。提示按钮热区不小于 80×80。返回按钮热区不小于 80×80。
- 结算盖住画面。胜利显示「下一关」和「返回」。最后一关胜利把「下一关」换成「返回首页」。失败显示「重试」和「返回」。本局不出现第二个分享入口。

首页列出关卡。第 1 关始终可进。通过一关后解锁下一关。已通过的关可以重玩，重玩不再改变解锁进度。首页有「继续」，进入最近一个未通过的已解锁关；全部通过后进入最后一关。

第一关在第一次点到图内空白时用一句话说明「点出两张图不一样的地方」。不在开场堆规则。

## 关卡内容

关卡是数据，不是写死在场景脚本里的分支。每一关要写清：名称、倒计时、两张图、每个不同处在图片像素里的圆心和半径、名字和提示。

要找的数量必须等于不同处个数。图片像素坐标的原点在该图左上角，y 向下。上图和下图使用同一套坐标。

第一版交付 3 关。第 1 关「山羊草地」和第 2 关「厨房里的猫」来自外部茬图包：上下两张 `jpg`，各 5 处不同，坐标写在包内的 `level.json`。第 3 关的画面和 `level.json` 由规格生成。换成绘制好的两张图时，不同处坐标仍按同一套字段填写。

关卡图和关卡配置放在游戏包外面。首页能看到的关卡名单也从外面的目录读取。玩家点进某一关时，只拉这一关的配置和两张图。加载过程中显示「关卡加载中」和进度。加载完成、两张图摆好之后才开始倒计时。加载失败时显示「关卡加载失败」，可以重试加载或返回首页。失败这一下不扣时间，也不扣提示次数。

同一关里玩法失败后的「重试」重置倒计时和圈，画面留在内存里，不再显示「关卡加载中」。离开关卡再进来，如果这关还在本地缓存里，就直接用缓存开局；缓存失效或文件有更新时重新拉取。

## 微信产品约束

这些约束来自微信小游戏设计规范和开发技能，第一版在浏览器里就要按这个布局做，避免以后重排。

- 基准分辨率 750×1334。高频按钮放底部，只读信息放顶部。
- 游戏包只放引擎和壳界面：首页、结算、加载页。主包不超过 4MB，启动时尽量压到 2MB 以内。关卡配置和两张图全部在包外，按关拉取，不占主包和分包额度。
- 关卡内容地址使用 HTTPS。微信上这个域名要配进下载文件合法域名。浏览器上图片要允许跨域，否则画布读不到纹理。
- 一局最多一个分享节点，不强制分享。第一版可以不放分享。
- 激励视频只放在失败这种自然节点，看完才给奖励，并且提供不用广告也能重试的路径。第一版不接广告，失败直接重试。
- 免费玩家可以打完已有关卡。
- 切到后台时暂停。第一版对局中途不恢复到点到一半的状态之外的额外存档；解锁进度必须还在。回到前台继续本关倒计时，已经套上的圈还在。

## 验收

- 点中上图或下图的同一处不同，两边都出现圈，圆点亮起一个，计数增加，该位置不能再点。
- 点在图内空白不改变计数和剩余时间。
- 倒计时到 0 且没找齐时失败，重试后圈消失、提示次数恢复、时间恢复，且不再次出现整段加载进度。
- 找齐后立刻胜利。最后一处找齐也算胜利。
- 提示最多 3 次，每次在上下两张图上同时标出下一个未找到的位置。
- 第 1 关可进。通过后下一关可进，未通过的更后关不能进。刷新页面后解锁还在。
- 全部界面在 750×1334 画布上，窄屏按比例缩小并居中，两张图都不被裁到屏外。
- 冷启动后的游戏包里没有关卡图。点进第 1 关会先出现加载进度，加载完才看到上下两张图并开始倒计时。
- 把关卡内容地址断开后点进关卡，停留在「关卡加载失败」，可以返回首页。恢复地址后重试加载能进入关卡。
- 第 1 关加载外部包的上下两张图，点中犄角、眼睛、斑纹、小花、铃铛都会套圈。
- 第 2 关加载外部包的上下两张图，点中果酱罐、猫的斑纹、陶罐、麻袋苹果、地上苹果都会套圈。
- 改第 3 关的规格后重新生成，得到的两张图在每个不同处圆心上像素不同，`level.json` 能通过校验。生成不会覆盖第 1、2 关。
